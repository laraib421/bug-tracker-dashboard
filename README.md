A lightweight, zero-dependency **Kanban-style bug tracker** for QA teams with a 3D-glass dark UI.

## ✨ Features
- 📝 Log bugs with title, steps to reproduce, severity & environment
- 🗂️ Drag-and-drop workflow: **Open → In Progress → Ready for Retest → Closed**
- 📊 Live stats: total, open, critical, retest, fix rate
- 🔍 Search + severity filter
- ⬇️ Export the bug list to **CSV**
- 💾 Saved in your browser (localStorage)
- 🛡️ HTML-escaped input (XSS-safe) · 📱 responsive

## 🚀 Run
Just open `index.html` in a browser — or enable **GitHub Pages** (Settings → Pages → main branch) to host it.
